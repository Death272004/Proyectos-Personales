# 🍕 Urban Slice — Página de Pizzería

Página web estática de una pizzería ficticia llamada **Urban Slice**, creada
con **HTML** y **CSS**.

## ✨ Contenido

- Barra de navegación con logo y enlaces.
- Sección de bienvenida con imagen de fondo.
- Carta destacada con 5 pizzas, descripción, precio y foto:
  - Margherita — $10.00
  - Pepperoni — $12.00
  - Vegetariana — $11.00
  - BBQ Chicken — $13.00
  - Cuatro Quesos — $14.00

## 🛠️ Cómo verlo

Al ser HTML/CSS puro, no necesita dependencias ni servidor. Solo abre el
archivo en tu navegador:

```bash
# Opción 1: abrir directamente
start index.html      # Windows
xdg-open index.html   # Linux
open index.html       # macOS
```

O usa un servidor local si prefieres:

```bash
python -m http.server 8000
# y abre http://localhost:8000
```
